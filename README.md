# Moon Tracker

출사를 위한 천체 내비게이터입니다. 지금 위치와 폰이 향하는 방향을 바탕으로 달, 행성, 별자리가 어느 쪽에 얼마나 높이 떠 있는지 나침반으로 안내합니다.

**▶ 앱 열기: https://kjso521.github.io/moon_tracker/web/**

설치 없이 브라우저에서 바로 쓸 수 있고, 홈 화면에 추가하면 주소창 없는 앱처럼 실행됩니다. 한 번 열어 두면 인터넷이 약한 출사 장소에서도 작동합니다.

---

## 주요 기능

- **천체 나침반**: 폰을 돌리면 천체 아이콘이 나침반 둘레를 따라 움직이고, 방향이 맞으면 노란색으로 바뀌며 진동합니다.
- **높이 안내**: 폰을 세워 들면 "위로 12° 기울이십시오"처럼 천체의 고도까지 안내합니다.
- **3D 나침반**: 폰을 세우면 나침반이 바닥에 놓인 원판처럼 눕고, 천체가 고도만큼 떠올라 높이를 한눈에 가늠할 수 있습니다.
- **27개 천체**: 달, 태양, 행성 5개, 주요 별자리 17개, 은하수 중심·안드로메다 은하·플레이아데스 성단.
- **천체 안내 카드**: 별자리 모양과 찾는 법, 목성 위성의 현재 배치, 토성 고리의 기울기, 금성의 위상, 골든아워 등을 보여 줍니다.
- **시간 이동**: ±24시간 또는 원하는 날짜의 하늘을 미리 볼 수 있습니다.

## 설치하기

| 기기 | 방법 |
|---|---|
| Android · Chrome | 앱 주소를 연 뒤 ⋮ 메뉴 → **앱 설치** (또는 홈 화면에 추가) |
| Android · 삼성 인터넷 | 주소창의 설치 아이콘, 또는 ≡ 메뉴 → **현재 페이지 추가 → 홈 화면** |
| iPhone · Safari | 공유 버튼 → **홈 화면에 추가** |

처음 실행하면 **시작하기**를 누른 뒤 위치 권한을 허용하십시오. iPhone에서는 방향 센서 권한도 함께 허용해야 합니다.

> 이전에 바로가기로 추가한 아이콘이 브라우저로 열린다면, 아이콘을 지우고 위 방법으로 다시 설치하십시오.

## 사용법

### 나침반 읽기

- 원 위쪽의 **삼각형**은 폰이 가리키는 방향입니다.
- 원 둘레의 **아이콘**은 천체의 방향입니다. 아이콘이 삼각형에 오도록 몸을 돌리면 됩니다.
  - 달은 실제 위상 모양으로, 행성은 점(●), 별자리는 반짝이(✦), 성운·은하는 흐린 점으로 표시됩니다.
  - 지평선 아래에 있는 천체는 흐리게 표시됩니다.
- 방향이 가까워질수록 나침반이 밝아지고, **±3° 안으로 맞으면 노란색**으로 바뀌며 진동합니다.
- 아래 방위 줄에는 가장 가까운 천체의 방위각이, 그 아래에는 돌릴 방향과 각도가 표시됩니다.

### 폰을 드는 방법

- **눕혀서 들면** 폰 윗변이 가리키는 방향을 기준으로 안내합니다.
- **세워서 들면** 후면 카메라가 향하는 방향을 기준으로 안내하고, 천체의 높이도 함께 안내합니다. 카메라로 구도를 잡을 때 이 방법이 편리합니다.

### 2D / 3D 나침반

제목 줄 오른쪽의 **3D** 버튼으로 켜고 끕니다. 3D를 켜고 폰을 세우면 나침반이 원판처럼 눕고, 지평선 위의 천체는 점선 기둥 위로 고도만큼 떠오릅니다. 전환할 때는 부드럽게 모양이 바뀝니다.

### 천체 고르기

왼쪽 위 **☰** 버튼 → **천체 표시**에서 고릅니다.

- 태양계 · 별자리(계절별) · 성운·은하로 나뉘어 있으며, 카테고리를 접고 펼 수 있습니다.
- 카테고리별 **전체 선택**, 모든 천체의 **모두 선택**을 지원합니다. 모두 해제하면 달만 남습니다.
- 여러 천체를 켜면 **폰이 가리키는 방향에서 가장 가까운 천체**를 자동으로 안내합니다.
- 삼각형 근처(±20°)의 천체는 아이콘 위에 이름이 표시됩니다. 안내 중인 천체는 굵고 밝게, 나머지는 얇고 흐리게 표시되어 겹쳐도 구분됩니다.

### 천체 안내 카드

나침반의 **천체 아이콘**이나 아래 **방위 줄(›)**을 누르면 카드가 열립니다. 손잡이를 아래로 끌거나 바깥을 누르면 닫힙니다.

| 천체 | 카드 내용 |
|---|---|
| 별자리 | 별자리 모양(별 크기 = 밝기), 기준점, 주요 별, 찾는 법 |
| 성운·은하 | 주변 별자리 위의 위치, 거리 |
| 달 | 현재 위상, 월령, 다음 보름달과 삭 |
| 태양 | 아침·저녁 골든아워와 블루아워 |
| 행성 | 현재 모습(금성·수성의 위상, 목성 위성 배치, 토성 고리 기울기), 밝기, 거리, 관측 가능 여부 |

### 시간 이동

아래 시간 막대를 좌우로 움직이면 ±24시간 범위의 하늘을 미리 볼 수 있습니다. 날짜와 시각을 누르면 원하는 날짜로 이동하고, **지금으로**를 누르면 현재 시각으로 돌아옵니다.

### 방위 보정

폰의 나침반은 자북을, 천체의 방위는 진북을 기준으로 합니다. 한국은 자북이 진북보다 서쪽으로 약 9° 치우쳐 있어 기본 보정값을 **-9°**로 설정했습니다.

방향이 어긋난다면 실제로 보이는 천체(달이나 북극성)를 폰으로 정확히 겨눈 뒤 **☰ → 방위 보정 → 지금 방향으로 보정**을 누르십시오. 보정값은 기기에 저장됩니다.

### 위치 직접 입력

다른 장소의 하늘을 미리 보고 싶을 때 **☰ → 상태 → 위치 직접 입력**에서 위도와 경도를 입력하고 **적용**을 누르십시오. **현재 위치로**를 누르면 GPS 위치로 돌아갑니다. 직접 입력한 위치는 앱을 다시 열면 현재 위치로 돌아갑니다.

## 정확도를 높이는 팁

- 폰을 8자 모양으로 몇 번 흔들어 나침반 센서를 보정하십시오.
- **자석이 들어간 폰 케이스**(지갑형, 맥세이프 링 등)는 방향을 크게 틀어지게 할 수 있습니다.
- 자동차, 철제 난간, 건물 근처에서는 방향이 어긋날 수 있습니다. 탁 트인 곳에서 사용하십시오.
- 방향이 계속 어긋나면 북극성이나 달을 기준으로 **방위 보정**을 하십시오.

---

## 개인정보

- 위치 정보는 천체 위치를 계산하는 데에만 쓰이며, **기기 밖으로 전송되지 않습니다.**
- 천체 선택, 방위 보정값, 3D 설정은 기기의 브라우저 저장소에만 저장됩니다.
- 회원가입, 광고, 분석 도구가 없습니다.

---

## 지원 환경

- Android의 Chrome, 삼성 인터넷에서 확인했습니다.
- 위치와 방향 센서는 HTTPS 주소에서만 작동합니다. 위의 앱 주소를 사용하십시오.
- 방향 센서가 없는 PC에서는 방향과 기울기를 슬라이더로 시험해 볼 수 있습니다.

## 개발

별도의 빌드 과정이 없는 정적 웹앱입니다.

```bash
python3 -m http.server -d web 8000   # http://localhost:8000
```

배포할 때는 `web/version.js`의 버전과 날짜를 올립니다. 이 값이 앱의 버전 표시와 오프라인 캐시 이름을 함께 정합니다.
