Project: Moon Tracker

목표
- 이 프로젝트는 출사를 위한 천체 추적기 앱을 만드는 것입니다.
- 가벼운 모바일 앱, 혹은 가능하다면 웹 앱에서 시간/내 위치/보는 방향 정보를 받아와서 표현해도 됩니다. (가능하면 둘 다.)
- 1차적으로는 달을 주요 타겟으로 잡고 개발 중이나, 1차 완성 후 다른 주요 천체(금성, 목성 등)를 추가할 계획도 있습니다. 옵셔널하게 켜는 기능을 넣고자 합니다.

현황
- Flet 기반으로 Logic과 UI를 얼추 만들었습니다.
- 다만, Mobile(Android)로 Geolocator, Magnetometer를 연동하고자 하였으나, 테스트 단계에서 지속적으로 실패 중입니다.
- 이에 Claude의 도움을 받아 완성을 해보고자 합니다.

참고 사항
- 초기 기획한 아이디어를 draft.pptx에 저장해두었습니다. 참고하시면 되고, 여기서 더 Fancy하게 develop해주셔도 됩니다.
- github repository도 만들었으나, 초기 저장 후 업데이트 하지는 않고, 본 폴더를 새로이 만들어 사용 중입니다. Claude에서 편집 시 다음 Repository를 마음껏 써도 됩니다. https://github.com/kjso521/moon_tracker.git
- Font는 국문은 Pretendard, 영문은 Montserrat를 사용하고자 합니다.
